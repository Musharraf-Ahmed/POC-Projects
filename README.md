# POC Projects

This repository contains proof-of-concept projects and experiments.

## Projects

### [AI-Powered Accessibility Scanner](AI-Powered%20Accessibility%20Scanner/README.md)

A Python prototype that uses Playwright and axe to collect accessibility findings, enriches them with AI-generated explanations, stores them in PostgreSQL, and displays them in a Streamlit dashboard. See the project README for its layout, API, setup notes, and current limitations.
